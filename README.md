# BeliTani | Group Project for OMC

Developed a farmer-to-customer platform designed to simplify the process of selling and purchasing agricultural produce by connecting farmers directly with customers and reducing reliance on middlemen.

The platform aims to help farmers receive more reasonable prices for their produce while allowing customers to purchase fresh produce at more affordable prices.

**Key features:**

* Direct platform connecting farmers and customers
* Separate login and access for administrators, farmers, and customers
* Farmer-focused interface for managing and promoting agricultural produce
* Weather information to help farmers plan their agricultural activities
* Crop information and guidance for different types of produce
* Harvesting information to help farmers understand appropriate harvesting practices
* Database integration for managing application data

**User roles:**

* **Admin:** Manages and oversees the platform
* **Farmer:** Accesses agricultural information and manages produce
* **Customer:** Browses and purchases available produce directly from farmers

**Technologies:** Visual Basic, mySQL
